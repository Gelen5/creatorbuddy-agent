# CreatorBuddy Agent 工作台流程

## 首用动线

```text
进入工作台
  -> 连接自己的账号
  -> 补账号画像：定位 / 目标用户 / 内容方向 / 商业目标 / 核心产品
  -> 选择对标行业并添加对标账号
  -> 记录第一条内容资产
  -> 读取自有内容与公开信号
  -> 生成评分后的下一条选题
  -> 生成对应平台草稿
  -> 发布前检查
  -> 记录发布时间、指标、评论和转化
  -> 2h / 24h / 48h / 7d 复盘
  -> 生成 post-review 复盘报告
  -> 用户确认策略候选
  -> 下次生成前读取已确认策略
```

## 证据边界

- 自有账号后台数据是账号事实。
- 公开对标内容是趋势样本，不是自己的后台数据。
- AI 推荐是排序判断，不是爆款保证。
- 缺少发布时间、指标、评论或转化时保留空值并标注待补充。
- 单次复盘只能生成策略候选，确认后才能进入策略库。

## CLI 与 UI 操作映射

| UI 操作 | CLI |
| --- | --- |
| 连接我的账号 | `set-account` |
| 补账号画像 | `set-profile` |
| 添加对标账号 | `add-benchmark` |
| 检查首用状态 | `onboarding-status` |
| 记录内容资产 | `add-content` |
| 记录发布后数据 | `review` |
| 生成发布后复盘 | `post-review` |
| 生成今日选题 | `today` |
| 生成草稿 | `draft` |
| 发布前检查 | `precheck` |
