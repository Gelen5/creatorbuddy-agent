# CreatorBuddy Agent 工作台流程

## 首用动线

```text
进入工作台
  -> 连接自己的账号
  -> 补账号画像：定位 / 目标用户 / 内容方向 / 商业目标 / 核心产品
  -> 选择对标行业并添加对标账号
  -> 记录第一条内容资产
  -> 读取自有内容与公开信号
  -> 生成评分后的下一条选题
  -> 生成对应平台草稿
  -> 发布前检查
  -> 记录发布时间、指标、评论和转化
  -> 2h / 24h / 48h / 7d 复盘
  -> 生成 post-review 复盘报告
  -> 用户确认策略候选
  -> 下次生成前读取已确认策略
```

## 证据边界

- 自有账号后台数据是账号事实。
- 公开对标内容是趋势样本，不是自己的后台数据。
- AI 推荐是排序判断，不是爆款保证。
- 缺少发布时间、指标、评论或转化时保留空值并标注待补充。
- 单次复盘只能生成策略候选，确认后才能进入策略库。

## 正式版闭环验收

运行：

```powershell
python scripts/creatorbuddy.py workflow-audit
```

该命令不会生成内容，而是检查当前 workspace 是否已经具备可验证证据：

1. 首用流程；
2. 账号配置中心；
3. 内容资产数据库；
4. 今日内容机会报告；
5. 小红书草稿与发布前检查闭环；
6. 对标账号蒸馏；
7. 发布前检查报告；
8. 发布后复盘报告；
9. 策略候选、人工确认、下次生成前读取的自成长链路。

只有所有项目都有对应文件或结构化数据时，才返回 `ok: true`。

## Web 控制台页面

第一版 Web 不做复杂大屏，只保留 5 个可用页面：

| 页面 | 目的 |
| --- | --- |
| 首页 | 打开后立刻知道今天该做什么 |
| 账号中心 | 配置我是谁、卖什么、做什么平台、对标谁 |
| 内容机会 | 查看今日推荐、评分、证据和草稿动作 |
| 内容库 | 查看已发布内容、指标、转化、复盘状态 |
| 复盘中心 | 查看复盘提醒、策略候选和已生效自成长策略 |
